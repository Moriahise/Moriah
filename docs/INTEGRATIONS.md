# MORIAH study integrations

The public four-hour workflow runs `scripts/ecosystem.py` before validation and deployment. Configuration is in `config/ecosystem.json`. The collector reads the owner's published catalogues and compact Sanhedrin release; it does not run migration or cleanup scripts and does not modify any upstream project.

- **Shiurim / Haftarot:** exact published catalogue IDs and actual Haftarah directory URLs. The source's weekly convention applies: Sunday–Tuesday retain the preceding Shabbat; Wednesday–Saturday select the coming Shabbat. Israel/Diaspora follows the selected city. Special Shabbat and festival Haftarot override ordinary portion names when the published directory supplies the matching study.
- **Calendar:** `@hebcal/core` is bundled locally, so navigation and local zmanim do not require an API round trip. Hebrew date changes at the selected city's sunset. The Israel date/clock is shown separately. Hebrew and civil months, holidays, weekly readings, eight daily zmanim, candle lighting and Havdalah are available. Jerusalem candles: 40 minutes; other configured cities: 18 minutes; Havdalah: 8.5 degrees; sea level. Customary differences are stated. Library licence is distributed in `assets/hebcal-LICENSE.txt`; buildable source is in `src/` and `package-lock.json`.
- **Niggunim:** collection links come from the actual Sanhedrin music cards. Track and playlist metadata is parsed as JSON from each collection's published seed, never evaluated as code. Nine collections currently expose 607 tracks. Daily selection and a 90-second rotation when idle; rotation pauses during playback, keyboard focus in the section, hidden tabs or reduced-motion preference. Playback requires a user click. YouTube queues use the privacy-enhanced player; original audio remains on its source host. Availability depends on the original recording provider.
- **Sanhedrin Q&A:** selection is restricted to records with existing answers, using the current manifest, facet ordinals, page files and ID locator shards. Eighteen cached cards (nine per language) provide varied daily selections and a “More questions” button. Attributed answer excerpts are included for CC-licensed/local material. Other records link to the full existing answer without reproducing its text. `qa.html?id=...` remains the authoritative reader. Original-language titles are not falsely labelled translations.
- **Zohar:** current weekly title and source excerpt link to the matching published study. All 54 portions remain visible/searchable; only published studies receive individual study links. Currently three published lessons exist. New catalogue entries become available at the next successful refresh.
- **Jastrow:** inline search opens the complete dictionary in an on-demand iframe, with a new-tab fallback. Supported deep-link format is `#view=dictionary&q=...`.
- **Daf Yomi:** calculation matches the owner's modern 2,711-day cycle anchored on 1975-06-24. The daf changes at Israel civil midnight, independent of the browser's timezone. Published IDs open directly; an unpublished date opens the reader's supported `?date=` route. Manual date navigation does not replace the front-page “today” card.

Source failures preserve the last successful section. State and timestamps are recorded in `data/ecosystem.json`; new song collections without metadata remain linked but are excluded from playlist rotation. Source availability does not imply that a study or recording has been independently reviewed.

Run `npm run build:integrations`, `npm test`, `python -m unittest discover -s tests -v`, `python scripts/build.py`, and `python scripts/verify_build.py` after changes. The frontend bundle is committed for private previews and versioned by content hash to avoid stale caches. Existing frozen weekly issues are unchanged.
